# Bar Chart

## Purpose

Grouped or single-series vertical bar chart for dashboards. Config-driven — apps pass `categories` + `series` data only.

## Import

```ts
import { BarChart } from "@erp/miniapp-ui";
```

## Usage

```tsx
<BarChart
  categories={["Jan", "Feb", "Mar"]}
  series={[
    { name: "Expected", data: [40, 55, 48], className: "bg-muted-foreground/30" },
    { name: "Generated", data: [32, 61, 50], className: "bg-primary" },
  ]}
  showLegend
  height={192}
  aria-label="Leads generated by month"
/>

{/* Single series with one highlighted bar */}
<BarChart
  categories={["Mon", "Tue", "Wed", "Thu"]}
  series={[{ data: [92, 88, 70, 95], className: "bg-teal-600" }]}
  highlightIndex={2}
  highlightClassName="bg-orange-500"
  height={128}
/>
```

## Props

| Prop | Type | Notes |
| --- | --- | --- |
| `categories` | `string[]` | X labels |
| `series` | `{ name?, data, className? }[]` | One or more series; `className` = Tailwind fill |
| `height` | `number` | Plot height px (default 160) |
| `highlightIndex` | `number` | Highlight one category (single series) |
| `highlightClassName` | `string` | Fill for highlighted bar |
| `showLegend` | `boolean` | Legend from series `name` |
| `barClassName` | `string` | Shared bar thickness |

## Accessibility

Renders `role="img"` with `aria-label`. Prefer a descriptive label for the dataset.
